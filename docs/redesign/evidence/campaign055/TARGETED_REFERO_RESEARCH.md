# Campaign 055 — Targeted Refero Research

**Purpose:** targeted reference study for the surfaces Campaign 052 classified
as weak. This is not a mood-board exercise and not a new visual direction.
Signal Arcade stays; the research below is used only to sharpen composition,
pacing, hierarchy and object presentation.

**Method:** Refero semantic screen/flow search, then full screen retrieval and
full-resolution inspection of the strongest candidates. References are
comparators, not templates; no Refero asset, layout or copy is copied into the
product.

## Searched angles

| Angle | Query | Platform |
| --- | --- | --- |
| Mobile game storefront / catalog | "mobile game storefront catalog browse with featured game cards" | iOS |
| Game detail with one CTA | "game detail screen with hero art and single play call to action" | iOS |
| Result / completion / celebration | "puzzle game level complete score stars next level" | iOS |

| Collectibles | "collection album stickers cards locked unlocked collectible" | iOS |

## References actually used (full retrieval + image inspection)

### 1. Apple Games — storefront list (`41d9754e-d30b-4b65-919b-ef6e3b15a92f`)

- Full-bleed art carousel at the top of the catalog with the game's own
  screenshots carrying promo copy — identity is the first thing visible.
- Below it, compact horizontal identity rows: square game icon + bold game
  name + rating + genre + one small "View" key. Metadata is subordinate and
  dense; no repeated banner→badge→title→paragraph stack.
- **Borrowed:** art-first identity with metadata compressed into one line;
  the discipline that a catalog row can prove a game in one glance.
- **Rejected:** dark storefront chrome and ratings (this product is offline
  and 1-player; no ratings exist), and carousel-only browsing.

### 2. LEGO Builder — poster grid (`94169960-8458-46a4-ba0c-cfa3ca0eae80`)

- 2-column grid of poster tiles; every tile has its own bright art field and a
  quiet white label plinth; the grid stays calm because each tile repeats the
  same *slot* but not the same *art*.
- Search and a color field sit above the grid as a bold header, not as another
  card.
- **Borrowed:** the poster-tile grid as the scalable browse-all structure for
  42 games; art surface + small identity plinth; colored header field.
- **Rejected:** the bright yellow brand field and product-photo realism
  (Signal Arcade keeps paper/ink and code-native geometry).

### 3. Netflix — title detail (`06ea1fd1-f36f-4950-95e8-88d85663e2af`)

- One full-bleed hero owns ~60% of the viewport; the title sits on the art;
  one metadata pill; **one** full-width CTA; everything else (share, related)
  lives in a bottom sheet.
- **Borrowed:** hero dominance with a single CTA and the rule that secondary
  data must earn its way above the fold.
- **Rejected:** the dark cinematic grading and the share/social sheet (no
  social features exist in this product).

### 4. Duolingo — level-complete (`0ec5a15e-7127-4f1c-88bd-a4556520f9b2`)

- A full-screen dark event: radiating beams, one object (mascot + coin),
  one heavy headline, one supporting sentence, one giant key.
- **Borrowed:** the result screen as a single authored event with one object
  and one action; supporting metrics are not allowed to compete.
- **Rejected:** mascot/character licensing and celebratory tone on weak
  performance (this campaign adds honest non-celebratory bands).

### 5. (Not Boring) Habits — completion (`b897dc1c-ccba-4d24-b1fd-0fe5c541a5bd`)

- Completion as a typographic artifact inside an object; "YOU COMPLETED THE
  BASE!" is the visual itself; one SHARE control; "TAP TO CONTINUE".
- **Borrowed:** the idea that a completion statement can *be* the artwork,
  and the extreme action economy (one clear next action).
- **Rejected:** the all-caps destructive scale as a general recipe; the
  product's result bands must stay readable at font scale 2.

### 6. Fable — sticker collection (`be54d014-cd6d-4183-8db6-3dc123427af2`)

- A 3-column grid of collectible tiles on a consistent dark tile plate; each
  tile centers one object; owned items are indistinguishable at a glance from
  locked ones only by their content, not by chrome noise.
- **Borrowed:** consistent tile plate + one centered object per collectible;
  grid density over list density.
- **Rejected:** dark tile color and raster swag; this product renders
  collectible objects code-native.

### 7. Brilliant — "For you" daily (`c118f203-312f-4a59-bd8d-18a0ce4c1191`)

- Streak rendered as a row of day dots with a lightning glyph and one lime
  accent; the daily task is a large art-forward interactive card with a
  question bubble.
- **Borrowed:** streak as a compact rail of day cells instead of a stat-card
  grid; one art-forward daily object.
- **Rejected:** the subscription carousel and mascot-adjacent illustration.

### 8. Headspace — locked content grid (`b04b5b28-6a0f-412f-8bcc-b67f49e8c440`)

- Locked levels shown as a calm grid of circular outlines with lock glyphs and
  numbers; locked content is aspirational, quiet and readable.
- **Borrowed:** locked states as quiet outlined objects inside the same grid
  as owned objects (used for Rewards collection slots).
- **Rejected:** paywall framing (this product has no monetized unlock).

## Synthesis — what this campaign takes from the references

1. **Catalog pacing (Apple Games + LEGO):** a featured art shelf plus a
   dense poster-tile grid; identity before metadata.
2. **Detail dominance (Netflix):** one full-bleed stage, one CTA, one line of
   metadata; records move below a clear fold into report grammar.
3. **Result event (Duolingo + Not Boring):** one object + one band headline +
   one action; metrics become a supporting strip.
4. **Identity rail (Brilliant):** streak/days as a compact rail; a daily
   object owns the first viewport.
5. **Collection grid (Fable + Headspace):** consistent collectible plates with
   quiet locked states and one object per tile.
6. **Reality check (Campaign 052's own set: Introspect, CapWords, Stardust):**
   single focal object, tactile depth around the task, authored dark
   atmosphere — already aligned with Signal Arcade; no direction change.

## Explicitly not borrowed

- No ratings, reviews, social, sharing, subscriptions, paywalls, mascots,
  characters, generated characters, or raster production art.
- No new palette, no gradient background systems, no glassmorphism.
- No carousel-only browsing patterns that hide content.
