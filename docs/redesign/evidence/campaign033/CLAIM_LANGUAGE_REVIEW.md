# Campaign 033 claim-language review

The overview language is intentionally limited to persisted training evidence:

- `Trained days`, `Sessions`, and `Per active day` count recorded sessions in the selected window.
- `Recorded movement` distinguishes no evidence, one-session insufficiency, and a comparison only when the sample supports it.
- Bounded windows compare a selected-window average with the lifetime average; all-time compares the first and latest recorded result.
- `Next consideration` describes an untrained, not-recent, or least-practiced domain. It does not rank intelligence, diagnose a condition, or promise an outcome.
- The composite is labeled `Overall recorded rating`, with its existing canonical-average derivation note.
- The empty state says how ratings start and does not present the initial value as an achieved performance.

No medical, neurological, intelligence, age-reversal, diagnosis, or guaranteed real-world-performance claim was added.
