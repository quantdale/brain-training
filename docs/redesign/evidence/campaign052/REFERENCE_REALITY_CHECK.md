# Campaign 052 reference reality check

This is a comparison against the intended Campaign 051 traits, not a design brief. Refero was used only as a visual comparator. No Refero asset or pattern was copied into the product.

## Refero comparison set

- [Introspect walkthrough screen](https://refero.design/screens/7bb384a9-978c-4b07-965c-15018b0f5198): a single focal illustration, strong hierarchy, generous space, and one dominant CTA.
- [CapWords vocabulary screen](https://refero.design/screens/5a839aa3-55d1-4bd2-8c77-cbd06f669cf6): layered cards, a central interactive object, progress, and tactile depth around the task.
- [Stardust quiz screen](https://refero.design/screens/8bc25896-a004-47e1-87e7-b4e7e6ebb95a): a fully authored dark atmosphere, clear progress, and a thematic visual world rather than a neutral dark dashboard.

These references are used as a reality check for focus, object confidence, tactile hierarchy, and authored dark mode. They are not implementation recommendations.

## Trait-by-trait comparison

### Playdate-like game-object confidence

**Succeeded:** Signal Arcade gives each game an identifiable object or board motif. The object appears in Games, Game Detail, gameplay, and Results, which is stronger than relying on text-only game names.

**Diluted:** The objects are mostly clean diagrams inside a shared card shell. They communicate rules, but rarely become characters, places, or expressive game worlds. The confidence is closer to an instructional schematic than a toy-like object with its own attitude.

### Authored dark mode

**Succeeded:** Dark Home, Games, Game Detail, and Result are not simple light-mode inversions. Backgrounds, surfaces, coral actions, mint/cyan game strokes, muted copy, and result reward panels are recolored as a coherent dark palette.

**Diluted:** The same card and stat hierarchy remains visible in dark mode. It feels authored at the token level, but not yet like a distinct nighttime world with a different compositional rhythm.

### Poster / game identity

**Succeeded:** Games discovery has strong poster-like framed art at the top of each card, and the suggested game has a visible domain, state, title, motif, and reason for recommendation.

**Diluted:** The lower half of the card repeats the same metadata, badge, title, description, and “Open game details” sequence. The poster signal is therefore surrounded by ordinary catalog UI and loses some of its distinctiveness.

### Tactile controls

**Succeeded:** Raised button shadows, thick borders, active pills, selected cells, green checks, red X states, and coral primary actions provide visible state changes. Gameplay feedback is especially legible.

**Diluted:** Many controls still look like standard rounded rectangles placed in a card. The visual feedback is clear but not consistently physical or playful across navigation, catalog, profile, and rewards.

### Brilliant-like task focus

**Succeeded:** Tutorial copy and gameplay instructions are direct. A game can be understood quickly, and the active game removes the tab bar and secondary navigation.

**Diluted:** Home, Progress, Profile, and portions of Games carry long explanatory copy and many metrics in the first view. The product often explains training around the task instead of letting the task carry the experience.

### Satisfying completion

**Succeeded:** The full workout provides a clear 4/4 saved state, XP, coins, and a return path to today’s progress. Results preserve score, accuracy, rounds, streak, and reward provenance.

**Diluted:** Standalone Results are primarily a vertically spaced metric report. A low-score timeout result is honest and useful, but it has little emotional lift; “Play again” is clear without being especially tempting.

### Game-library desirability

**Succeeded:** The catalog has breadth, suggested next logic, domain filters, Favorites, search, and recognizable game objects. Search for `memory` visibly changes the collection and exposes the library’s scale.

**Diluted:** Browsing is still a long stack of similarly shaped cards. The catalog proves that games exist, but does not consistently make each one feel like an object a young user wants to pick up immediately.

## Overall finding

Campaign 051 established a coherent signal-arcade vocabulary and materially improved the presence of game objects, active gameplay, dark mode, and completion state. The concept becomes generic mainly where the product returns to shared dashboard conventions: stacked cards, repeated metadata, analytics-style summaries, long Profile surfaces, and reward inventory. The strongest idea is present; it is not equally dominant on every surface.
