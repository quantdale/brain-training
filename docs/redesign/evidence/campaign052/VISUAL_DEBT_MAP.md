# Campaign 052 visual debt map

This map records problems only. It does not propose implementation fixes or begin Campaign 053.

| Major surface | Classification | Evidence / problem statement |
| --- | --- | --- |
| Home / Today | REFINE | The focus-module object is a credible product hook, but the title, workout promise, 0/4 state, progress bar, CTA, list, and streak content compete across one long dashboard-like surface. |
| Games discovery | RETHINK | The catalog has breadth and distinct motifs, but the immediate browse experience is a repeated stack of large cards whose metadata grammar outweighs game desire. |
| Game Detail | REFINE | The game is legible and Play is dominant, but the hero art behaves more like a mechanic diagram than a compelling game world, and Records pulls the lower surface toward analytics. |
| Tutorial / intro | REFINE | The tutorial is clear and honest, but its long card layout and explanatory copy make the pre-game moment feel like a product form rather than an anticipatory game reveal. |
| Active gameplay | KEEP | The board, round state, score, pause control, selected states, and feedback make the game itself the visual event. This is the strongest baseline to preserve. |
| Results | RETHINK | Session completion, reward, and next actions are present, but the metric list dominates the emotional moment; a low-score result reads as a report with a reward attached. |
| Progress | REFINE | The dial and time-window controls provide credible training evidence, but the page resembles analytics software and gives movement copy more weight than motivation. |
| Profile | RETHINK | Local-player identity exists at the top, then dissolves into a long sequence of streak metrics, achievements, data, and settings; the immediate reaction is record management rather than player identity. |
| Rewards | REFINE | Claiming and collection state are understandable, but small cosmetic previews, many locked items, and inventory-like progress make desirability weaker than the underlying reward mechanics. |
| Dark mode | KEEP | Dark Home, Games, Game Detail, and Result have a coherent authored palette and preserve game-object contrast; the visual direction is worth retaining as evidence of product personality. |

## Counts

- KEEP: 2
- REFINE: 5
- RETHINK: 3
- REPLACE_DIRECTION: 0
