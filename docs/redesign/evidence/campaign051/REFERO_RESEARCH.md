# Campaign 051 — Fresh Refero Research

**Observed:** 2026-09-19

This is the fresh research pass required by the Campaign 051 visual reboot
contract. Refero supplied ingredients and product patterns; no reference was
copied as a template.

## Style searches

Five distinct style searches were run:

1. `playful physical game console graphic product design`
2. `dark technical sports training luminous abstract`
3. `animated learning studio bright illustration`
4. `editorial product interface bold typography collectible`
5. `arcade game library visual identity high contrast`

Four promising styles were retrieved in full. Peloton was retained as a
supporting search result for performance hierarchy, not as the product's
primary visual foundation.

| Reference | ID | Extracted signal | Campaign 051 use and boundary |
| --- | --- | --- | --- |
| Playdate | `c91209ef-f7f3-4d2b-bf69-41b58e4e2cc2` | Vivid yellow/violet graphic blocks, flat color fields, collectible game imagery, restrained radius roles, and physical-control confidence | Primary inspiration for console geometry and game-object confidence; do not clone the hardware or exact palette. |
| Analogue | `16ce2487-3e9b-47e7-a456-cc416b23652a` | Obsidian/white contrast, precise geometry, restrained gray support colors, and product-as-object presentation | Borrowed for authored dark mode, crisp borders, and calm technical framing; not a monochrome conversion. |
| Active Theory | `9d795615-79d0-4544-ac5e-2858971c3b3b` | Void-black canvas, sparse luminous violet, contained abstract forms, compact technical typography, and disciplined radius roles | Used as a bounded dark/motion reference; the app remains readable and offline-training focused. |
| EVOKE | `1e802d79-598e-4745-aaa5-fa66c16608ad` | White ground with Rosy Flush/Sunbeam Yellow/Sky Cyan/Lavender panels, heavy display type, zero-radius billboard clarity | Borrowed poster energy and color blocking; rejected editorial excess and decorative noise. |
| Peloton | `1b7e4f5c-c3c2-48d5-8f34-3ecdd17f422e` | Dark performance credibility, restrained studio hierarchy, and one clear red action | Supporting reference for training seriousness; analytics stay quieter than play. |

The synthesis was not an average of these styles: Signal Arcade keeps
Playdate's physical game-object confidence, Analogue's precision, Active
Theory's disciplined dark contrast, and EVOKE's block clarity, then translates
them into a warm paper/ink cognitive-training console with code-native worlds.

## Flows

Fresh iOS flow searches covered:

- `completing learning session`
- `searching for games`
- `launching game`
- `claiming achievement reward`
- `exporting data from app`
- `personalized learning progression`

The following flows were retrieved in full and translated into product rules:

| Flow | ID | Extracted rule |
| --- | --- | --- |
| Vocabulary practice drill | `3822` | Single question, three choices, immediate green/red feedback, horizontal progress, and a completion card with Review/Start again. |
| Daily vocabulary quiz | `7861` | Home/daily CTA → intro → playful loading → question → Check → feedback → next → results → Done. |
| Start game and view challenge status | `9791` | Game detail Play/Challenge → loading → active play → updated challenge status; launch continuity matters. |
| Account data export | `7854` | Settings → Data controls → export confirmation → processing state; destructive/portable actions need explicit status. |

## Decision ledger

| Borrow | Reject |
| --- | --- |
| Flat high-contrast blocks, authored game objects, tactile controls, sparse empty states, one dominant action, contained progress, and explicit completion handoff | Warm-beige editorial default, endless white-card repetition, gradient-everything, random neon, glassmorphism, indigo default, badge clutter, and decorative analytics noise |

The resulting lock is **Signal Arcade / Cognitive Arcade Console**: paper and
ink for trust, signal pigments for play, a world-art stage for every game
family, and a restrained dark mode that is authored rather than inverted.
