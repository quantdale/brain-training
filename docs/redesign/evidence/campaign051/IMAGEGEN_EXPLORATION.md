# Campaign 051 — Imagegen Exploration

Image generation was available and used for three concept boards. These are
exploration aids, not production UI assets; generated text was intentionally
not used as product copy, and the implementation uses code-native shapes for
scalability, accessibility, and bundle discipline.

| Board | Direction | Generated file |
| --- | --- | --- |
| A | Signal Arcade | `imagegen/signal-arcade-concept.png` |
| B | Signal Lab | `imagegen/signal-lab-concept.png` |
| C | Bright Studio | `imagegen/bright-studio-concept.png` |

Prompts asked for fictional UI panels without logos, brand names, or readable
text. The generator still produced some incidental pseudo-copy/soft lighting;
that is why none of these boards is shipped in the app. The useful output was
the distinct contrast between the three systems and the confirmation that
Signal Arcade's hard-edged object language is the strongest anchor.
