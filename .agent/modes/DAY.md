# Day / Coexistence Mode

Purpose: allow autonomous development while the owner actively uses the PC.

- Up to ~7 coder agents only when useful and safely partitioned.
- One Android emulator.
- Avoid multiple simultaneous expensive builds/test runners.
- Prefer background/headless emulator operation.
- No host mouse/keyboard/focus automation.
- Use risk-based light validation after coherent swarm waves.
- Foreground user workload wins over maximizing throughput.

The user explicitly selects Day mode in the goal command.
