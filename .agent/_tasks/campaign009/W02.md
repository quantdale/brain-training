# Worker 02 — Speed + Math development

## Owned write surfaces
- `apps/mobile/src/games/speed-*/**`
- `apps/mobile/src/games/math-*/**`

Current inventory: speed-color-match, speed-quick-compare, speed-reaction-time,
speed-tap-rush (4 Speed); math-equation-builder, math-fast-math,
math-missing-operator (3 Math).

## Mission
1. **Audit** every game above with special attention to: monotonic timing
   sources; pause accounting (paused time must not count against the player);
   timer cleanup on unmount; render-latency independence of measured reaction
   times; duplicate-tap protection; timeout races; difficulty calibration;
   arithmetic solvability guarantees; division behavior (no div-by-zero, integer
   answers where promised); floating-point handling; distractor uniqueness.
2. **Fix real defects**, each with a regression test.
3. **Priority: add ONE new distinct Math game** (Math is the shallowest
   category at 3). Strong candidate: number-line estimation (place/match a
   value on a seeded number line; bounded error scoring; scale varies by
   difficulty). Other acceptable directions: numeric ordering under constraints,
   quantity/ratio comparison. NOT another fast-arithmetic clone — reject any
   design that reduces to Fast Math/Missing Operator/Equation Builder.
4. Speed addition ONLY if clearly distinct from all four existing mechanics;
   when in doubt, deepen existing games instead.
