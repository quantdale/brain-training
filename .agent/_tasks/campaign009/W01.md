# Worker 01 — Memory + Attention development

## Owned write surfaces
- `apps/mobile/src/games/memory/**`
- `apps/mobile/src/games/memory-*/**`
- `apps/mobile/src/games/attention-*/**`

Current inventory: memory, memory-grid-recall, memory-pattern-tap-back,
memory-running-order, memory-sequence-memory (5 Memory);
attention-odd-one-out, attention-symbol-tracker, attention-target-count,
attention-visual-search (4 Attention).

## Mission
1. **Audit** all 9 games for: deterministic generation (seeded RNG, no
   Math.random / Date.now in challenge paths); actual mechanic distinctiveness;
   difficulty progression; Adaptive profile behavior; challenge ambiguity;
   replay determinism; scoring normalization; timing correctness; pause/resume
   (board must be obscured while paused); double-submit protection; tutorial
   accuracy vs actual mechanics; accessibility answer leakage (e.g. hidden
   cells exposed to accessibility tree); QA force-state hooks; sensory feedback
   via canonical events; session persistence; render performance.
2. **Fix real defects**, each with a regression test.
3. **Add ONE genuinely distinct Memory game** if a real gap exists. Strong
   candidate: associative pair recall (learn seeded stimulus→response pairs,
   then cued recall with interference/re-pairing across rounds) — distinct from
   sequence, grid-pattern, running-order, and tap-back span mechanics.
4. **Attention has 4 games**: sustained vigilance (long watch stream, respond
   to standards, withhold rare no-go stimuli, deterministic stimulus schedule)
   is mechanically distinct from search/count/tracking — add it if it passes
   the README quality bar.
