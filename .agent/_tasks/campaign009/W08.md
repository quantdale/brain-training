## Mission — transactionality + idempotency above all
1. Test and harden: double taps on claim buttons; duplicate claim attempts;
   app relaunch mid-claim; concurrent operations racing; partial failure
   rollback (claimed marker + XP/currency commit atomically or not at all);
   negative balance prevention; repeat backup-import not duplicating rewards;
   daily/weekly rollover including timezone boundaries; large histories.
2. Achievements: progress computation correctness as catalog grows (36→40),
   aggregation snapshot builders, no regression of already-earned achievements.
3. Quests: deterministic pools, progress accuracy, claim idempotency.
4. Streaks: freeze/recovery costs+limits, atomic apply, milestone correctness.
5. Cosmetics: earn/unlock/equip state consistency, equipped references remain
   valid after imports/wipes.
6. No monetization decisions, no paid-tier rules, no new spend sinks without
   clear constitution alignment.
