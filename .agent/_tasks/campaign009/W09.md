## Mission — make Progress materially more useful using ONLY authoritative
## stored session data
1. Improve: domain trends; per-game trends; personal bests; difficulty trends;
   accuracy; reaction-time metrics where persisted; activity calendar;
   recent-vs-lifetime comparisons; staleness indicators; training balance
   across the 8 domains; explainability of every number shown (tie into
   `analytics/composite-explainer` patterns); empty states for new players.
2. HARD constraints: no medical/cognitive-efficacy claims; never fabricate or
   extrapolate metrics that are not in persisted sessions.
3. Audit scaling at thousands of sessions (queries behind these screens);
   report any unbounded scans to W10 via your report (do not edit db).
4. Charts must remain deterministic/testable; keep visual baselines stable or
   regenerate deliberately with a note.
