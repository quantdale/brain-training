## Mission
1. Audit: rating direction consistency; challenge expectation modeling; cold
   start behavior; caps/floors; manual easier-difficulty protection (players
   farming Easy must not inflate); Adaptive interplay; duplicate session
   handling (idempotency); historical import interactions; event timestamp
   ordering; NaN/Infinity guards on every arithmetic path; domain weighting;
   composite score transparency; XP ownership (no double-award paths).
2. Property/invariant tests: monotonicity where promised, boundedness,
   idempotent re-application, clamping at extremes.
3. Check whether a growing catalog (36→40) creates scaling or weighting biases
   in domain ratings/composite; fix or document.
4. No changes to the published curve semantics without strong evidence +
   explicit note in your report (parent reviews).
