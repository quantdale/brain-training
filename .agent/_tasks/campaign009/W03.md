## Mission (quality/content depth first)
1. **Audit**: content ambiguity (any item with >1 defensible answer);
   normalized-answer collisions (case/whitespace/punctuation normalization
   creating false matches or duplicate options); duplicate options within a
   round; content-pack validity (schema, versioning, item counts); seed
   determinism; solver correctness for logic games; unique-solution proofs
   (generators must be able to PROVE uniqueness, not assume it); bounded
   generation (no unbounded retry loops); difficulty progression coherence.
2. **Language must remain fully offline** — no runtime AI, no network. Content
   packs stay local + versioned.
3. **Logic generators** should carry independent validation/solver evidence:
   e.g. property tests that every generated puzzle has exactly one solution
   and is solvable by the shipped solver.
4. **Fix defects** with regression tests. Expand content banks where thin
   (bump contentVersion). Add a new game ONLY for a meaningful mechanic gap
   that survives the README quality bar.
