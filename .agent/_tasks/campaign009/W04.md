## Mission
1. **Audit**: rule-switch state machine correctness; cue/target race conditions
   (cue changes mid-trial); switch-trial vs repeat-trial scoring correctness;
   transform equivalence (isomorphic shapes counted equal regardless of
   representation); orientation/rotation correctness (clockwise vs
   counter-clockwise, coordinate-system handedness); coordinate transforms
   (rounding, bounds); round transitions; scoring normalization; timer/pause
   behavior; a11y (spatial info must not leak answers unintentionally but must
   remain playable with screen-reader labels where feasible).
2. **Property/invariant tests** where transforms are mathematically provable:
   rotation by 360° == identity; composition consistency; equivalence-class
   symmetry/transitivity; generator output always within declared bounds.
3. **Fix defects** with regression tests.
4. Both categories are at 5 games — expand only with a genuinely distinct
   mechanic that survives the README quality bar.
