## Mission — evidence-based performance audit
1. Audit with measurements, not vibes: Home / Games catalog / Progress /
   Rewards render paths; game board rendering; timer cleanup on unmount;
   audio/haptics object lifecycle (preload/release leaks); large lists
   (catalog grid, history lists); SQLite query patterns (N+1, unbounded
   scans, missing LIMIT); unnecessary rerenders (find real ones via test
   probes before recommending memo); subscription/interval/listener cleanup;
   memory retention across navigation; large JSON parse costs (backup export,
   content packs); synchronous work on hot interaction paths.
2. Do NOT cargo-cult React.memo/useMemo — every recommendation needs evidence.
3. Add stable regression guards as tests where they are deterministic and fast
   (e.g. "repository method does not issue N+1 queries", "unmount clears all
   timers"). Guards that would be flaky are worse than none.
4. Record measured baselines in your report for the parent to act on.
