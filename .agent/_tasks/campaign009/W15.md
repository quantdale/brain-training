   helpers there (do not mass-migrate existing tests — too conflict-prone).
4. Add a catalog-wide parameterized contract test ONLY if it does not overlap
   W05's shared-contract work (coordinate via report instead if unsure).
5. Do not weaken assertions to make CI green.
