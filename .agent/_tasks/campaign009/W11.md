# Worker 11 — Data portability + content integrity

## Owned write surfaces
- `apps/mobile/src/data-portability/**`
- `apps/mobile/src/content/**`

## Mission — attack backup/import/wipe adversarially
1. Test and harden: malformed backup JSON; wrong checksum; missing fields;
   unknown future version (must be rejected with clear error, not crash);
   very old versions; duplicate import; merge applied twice (idempotent);
   replace mode; rollback on mid-import failure; huge file handling; empty
   profile import; conflicting timestamps; currency duplication on re-import;
   session duplication on re-import; equipped cosmetic references surviving
   import/wipe; content-version compatibility checks.
2. Harden offline content registries and pack validators (`src/content/**`):
   schema validation, version gates, item-count integrity, deterministic
   ordering.
3. No backend/cloud work. Everything stays local + offline.

## Validation
- `cd apps/mobile && npx jest src/data-portability src/content`
- `npx tsc --noEmit` → only your files may have errors.
