## Anti-pattern source audit (gameplay-critical code only, non-test sources)

Method: repo-wide grep over `src/games/**` excluding `__tests__`, then manual
context reads of every distinct pattern class (screens, tutorials, components,
generators, reducers).

| Pattern | Hits | Verdict | Evidence / reasoning |
|---|---|---|---|
| `Math.random` | ~48 across 24 screens | LEGITIMATE | Only two shapes: seed draw `Math.floor(Math.random()*0xffffffff)` and session-id `${GAME_ID}-${Date.now().toString(36)}-${Math.random()…}`. Both are identity generation at session start; the drawn seed is persisted with the result, keeping gameplay reproducible. Zero hits inside generators/reducers/scoring. Generators are pure functions over injected SDK `Rng` (+ `.fork(salt)`); `createRng` binding exists in all 42 modules. `flexibility-task-switch/generator.ts:21` documents "Never use Math.random". |
| `Date.now` | ~90 across 42 games | LEGITIMATE | Three shapes: `completedAtMs` finalize stamp, `startedAtMs` session stamp, session-id salt. Wall-clock record stamps only — gameplay timing is monotonic: reducers of language-context-fit / language-word-chain / language-word-match / logic-deduction-table explicitly document "never Date.now()"; deadline logic uses lifecycle `elapsedMs()` / injectable `Clock`. |
| Reaction-time integrity | speed-reaction-time | CLEAN | Exemplary jitter-safe design: GO timer fires → `goAtMs = clock.now()` captured at actual display moment; `rtMs = clock.now() - goAtMs` with negative guard (screen.tsx:126–131, 279–289). No fabricated RTs found anywhere. |
| `setInterval`/`setTimeout` | 37 sites in 34 files | CLEAN | Every site: phase/paused guard (`if (state.phase !== … \|\| state.paused) return`) + effect cleanup (`clearTimeout/clearInterval`); set/clear counts balanced everywhere (extra clears are legit in-interval early-stops, e.g. memory-pair-recall study tick); tutorial demos use unmount-safe refs (speed-color-match advanceTimerRef). Countdown components use injectable clock monotonic deadlines. |
| Hard-coded answers | 0 | CLEAN | Heuristic sweeps for literal answer arrays / cheat markers found nothing outside `__tests__` fixtures. |
| Unseeded generation | 0 | CLEAN | All 36 procedural generators take `(rng, params, history)`; curated games (generatorVersion null: language-context-fit, language-word-chain + 1 more) are pack-driven. Reproducibility envelope documented per module. |

**Conclusion: no Critical/High/Medium/Low production defect found by this
audit.** The catalog-wide conventions (pause guards, dev-only QA gates,
seeded determinism, monotonic clocks) hold at runtime, not just textually.
