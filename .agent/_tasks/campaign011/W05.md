## Fixes performed

### New shared-host unit suites (all previously untested plumbing)
- `components/game-host/__tests__/use-game-session.test.ts` (NEW, 9 tests):
  `begin()` starts active lifecycle w/ namespaced identity; `claimFinalize`
  exactly-once per session + `begin()` re-arms it; `requestPause` refuses
  before begin / when already paused / when `canPause()` refuses (lifecycle
  stays active, no dispatch); latest-closure semantics across re-renders (ref,
  not stale capture); elapsed excludes paused segments (`pausedDurationMs`
  exact); `completeIfActive`/`abandonIfActive` idempotent, never leave a
  dangling/duplicated terminal transition; AppState background auto-pauses
  THROUGH the guarded path (canPause respected — no forced pause), foreground
  never auto-resumes; AppState subscription removed on unmount.
- `components/game-host/__tests__/timers.test.ts` (NEW, 9 tests): interval/
  timeout exist ONLY while `active`; handler-identity changes do NOT restart
  cadence (ref stability — pins the D1 invariant re-renders must not stretch
  or truncate windows); `ms` change reschedules from the NEW remaining (resume
  path); 0 ms timeout still fires on the next macrotask (the W18 edge);
  behavioral orphan-timer leak checks on deactivation/unmount
  (`jest.getTimerCount()` is polluted by React's scheduler here, so leaks are
  asserted by absence-of-fires, not timer counts).
- `components/game-host/__tests__/game-host.test.tsx` (NEW, 8 tests): back
  subscription mounted exactly once while `interceptBack`, disposed on unmount
  and on intercept-off, resubscribed on intercept-on (no orphan listeners);
  active-session back → one `onPause` + event consumed; paused-session back →
  consumed with NO further dispatch (overlay owns exit — no accidental
  abandonment); intro/results never subscribe; PauseOverlay mounts only for
  `paused && view === 'session'`; results render children verbatim without
  session chrome.

### Risk-area regressions (W18's declared areas)
- `speed-quick-compare/__tests__/screen.test.tsx` (+4, F2): window expiry
  resolves "Too slow" exactly once; answer exactly AT the deadline counts and
  the pending expiry cannot double-resolve; answer strictly AFTER the deadline
  is rejected and expiry owns the miss; pause-at-zero-remaining → resume still
  expires promptly (never buys time).
- `logic-order-path/__tests__/screen.test.tsx` (+2): full round solved exactly
  AT the budget boundary counts (strict `>`), pending expiry is a no-op
  afterwards; pick strictly AFTER the deadline ignored, expiry resolves the
  timeout, single resolution in stats.
- `attention-odd-one-out/__tests__/screen.test.tsx` (+1): tick cadence pinned —
  sub-tick advance leaves display untouched (pacing from the 250 ms host
  interval, not per-frame), first tick refreshes, and each new round re-arms
  the interval from its own escalated window (12s → 10.5s after a pass).
