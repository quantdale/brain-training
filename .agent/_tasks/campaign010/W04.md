# W04 — Memory / Logic Catalog Depth: one distinct new game

## Mission

Own a deliberately isolated catalog slot: implement ONE distinct advanced Memory OR Logic mechanic as a complete production vertical slice. Pick whichever fills the clearest gap after studying the catalog — quality over quantity.

Candidate Memory concepts:
- interference recall (careful: `memory-pair-recall` already does re-pairing interference — must be materially different)
- prospective cue memory (remember to act when a later cue appears)
- ordered reconstruction (careful: overlaps `memory-running-order`)
- n-back-lite (continuous-stream updating; must not clone `memory-pattern-tap-back` span mechanics)

Candidate Logic concepts:
- constraint elimination
- binary deduction (careful: overlaps `logic-code-cracker`)
- path planning (careful: overlaps `logic-order-path`, `spatial-grid-nav`)
- set classification (careful: overlaps `logic-rule-grid`)
- conditional reasoning (if/then inference chains)

Hard constraints:
- Document the distinctness rationale vs ALL existing games in the chosen domain (and near-neighbors in other domains).
