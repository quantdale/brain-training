## Implementation summary
Surfaced Workout V2 engine capabilities (wave 1) in the UI, per mission.

NEW `apps/mobile/src/components/workout/` (owned surface):
- `format.ts` — pure helpers `formatDurationMs` (ms → "45s"/"4m 30s"/"1h 05m", NaN/negative-safe) and `localDayStartMs` (local-midnight timestamp for a YYYY-MM-DD string). No clock/db/registry access.
- `template-picker.tsx` — `WorkoutLengthChips` (Short/Standard/Extended from engine `WORKOUT_LENGTHS`, shows game counts) and `WorkoutTemplateChips` (rotation-menu focus templates; `startedIds` renders a "· Started" marker while staying selectable for resume). Games-screen FilterChip styling: accentSoft/surface pills, MinTouchTarget 44pt, `accessibilityState.selected`, per-chip semantic testIDs via `testIDPrefix`.
- `completion-summary-card.tsx` — `WorkoutCompletionCard`: "Workout complete!" headline + `performanceBand(avgNormalized)` tone line (shell helper), ProgressTrack at completionRatio, stats line (games · XP · duration), polite live region. Template name resolved from instance-key metadata via engine `parseInstanceKey`/`getWorkoutTemplate`; registry-free.
- `history-row.tsx` — `WorkoutHistoryRow`: workout name, injected-clock relative day (`formatRelativeDay` + `finishedAt ?? localDayStartMs(date)`), progress ("n/m games" / "· In progress"), +XP; aggregated accessibilityLabel.
- `index.ts` barrel.

EXTENDED `apps/mobile/src/app/(tabs)/index.tsx` (home):
- Wired `useWorkoutTemplates({ domainRatings, recentGameIds })` alongside the untouched daily `useWorkout` flow (daily CTA remains primary).
- "More workouts" section (testID `home-workout-templates`): template chips from today's rotation (`suggestions` filtered to startable `kind === "template"`), started-today templates re-appended so partially played workouts stay resumable (start is idempotent per `(date, templateId, length)`), length chips, and a Start/Resume pill (`home-workout-template-start`) that calls `startTemplate(id, length)` then `router.push` into the instance's current game; in-flight disabled state; graceful caption when every suggestion is already started.
- Completion summary card (`home-workout-completion-card`) after finishing: latest completed TEMPLATE workout of today from engine history (newest-first scan), data-gated.
- Compact history section (`home-workout-history`): first 4 engine summaries as `WorkoutHistoryRow`s, testIDs sanitized from instance keys (`::` → `-`).
- Reward hint (W12 consumed READ-ONLY): `collectClaimableRewards(db)` count wrapped in its own try/catch inside `loadHome` (failure degrades to 0, never blanks the dashboard); Rewards quick pill shows `Rewards (n)` + updated a11y label only when n > 0.
- Visual-baseline discipline: all W24 sections gated behind `loaded` (+ `hasCatalog` for the picker); zero-state trees unchanged.

Conventions matched: shell/a11y primitives only, tokenized styles (Radii/Spacing), double-quote home style preserved, single-quote component style matching shell siblings, inline comments for invariants.
