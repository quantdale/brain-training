## Implementation summary

Landed the shared accessibility program as production primitives + adoption inside owned surfaces. No new game module (distinctness rationale n/a).

**New shared primitives — `apps/mobile/src/components/a11y/` (leaf modules) + `a11y.ts` barrel:**
- `touch-target.ts` — `MIN_TOUCH_TARGET`/`MinTouchTarget` moved here as single source of truth (barrel re-exports keep the old import path byte-compatible). Leaf-file split exists so game-ui can adopt the contract without an import cycle through the barrel.
- `font-scale.ts` — dynamic-type contract: `MAX_FONT_SCALE = 1.35`, `BOARD_GLYPH_FONT_SCALE = 1`, `effectiveFontScale(systemScale, max)` clamping to `[1, max]` (lower clamp = scale-aware minimum).
- `reduced-motion.ts` — canonical `usePrefersReducedMotion()` subscription plus pure selectors `motionValue(reduced, animated, static)` and `reduceDuration()`.
- `focus.ts` — `requestAccessibilityFocus(ref, attempts)` (setAccessibilityFocus with spaced retries for Android's attach/layout race, self-cancelling on unmount) and `useInitialA11yFocus(active)` ref hook.
- `announcements.tsx` — `announce()` imperative helper + `<LiveRegion message assertive>` component; platform-split by design (Android gets a real 1x1 live-region node, iOS/web get the imperative call) to avoid double announcements.
- `stats.tsx` — `StatGroup` (role=summary, children hidden from AT, one spoken stop) + `formatStats(pairs)` summary builder that skips empty metrics.
- `result-feedback.tsx` — `ResultFeedback` announcement pattern (headline + optional detail, polite/assertive) + pure `formatResultSummary`.
- `dialog.tsx` — `A11yDialog`: role=dialog (ARIA-style `role` prop because RN 0.86's legacy `accessibilityRole` union lacks 'dialog'), view-is-modal, importantForAccessibility="yes", initial SR focus on the card, title announce on open, Android back + scrim dismiss via `onRequestClose`, labelled Close button (44pt target). Self-contained (no game-ui imports) to keep the dependency graph acyclic.

**Adopted inside owned surfaces:**
- `themed-text.tsx` — default `maxFontSizeMultiplier={MAX_FONT_SCALE}` (1.35) on every ThemedText; caller-provided value wins; board-glyph opt-out stays `allowFontScaling={false}` (documented in header; matches existing game convention). lineHeight scales proportionally with the capped size.
- `game-ui/game-button.tsx` — both variants now derive their 44pt minHeight from the shared `MIN_TOUCH_TARGET` contract (was a local duplicate); added React 19 ref-as-prop (`ref?: Ref<View>`) so callers can drive screen-reader focus.
- `game-ui/difficulty-selector.tsx` — row announced as `radiogroup` "Difficulty"; chips keep button role + truthful selected state.
- `game-ui/pause-overlay.tsx` — reachability hardening for the campaign 009 grid-nav finding: explicit `importantForAccessibility="yes"` (opts back into the Android tree under any ancestor hiding), polite live region on the root (Android), imperative "Paused. Challenge hidden." announce on iOS/web only (avoids double-speak), and screen-reader cursor parked on Resume via `requestAccessibilityFocus`. Root intentionally still NOT `accessible` (existing contract test guards this).
- `game-ui/qa-panel-shell.tsx` — dev QA toggle now meets the 44pt touch-target contract.
- `game-ui/use-reduced-motion.ts` — thin re-export of the shared hook (public path preserved for `rewards/celebration.tsx` and games).

**Tests:** `components/a11y/__tests__/primitives.test.ts` — 6 small pure-logic tests (effectiveFontScale clamp/cap, motionValue, reduceDuration, formatStats skip-empty, formatResultSummary). Within the ≤8 cap; component semantics remain guarded by the pre-existing RNTL suites, which were left untouched.
