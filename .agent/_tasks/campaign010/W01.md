# W01 — Attention Catalog Expansion: attention-sustained-vigilance

## Mission

Build the strongest remaining distinct Attention mechanic: `attention-sustained-vigilance` — a SART-like sustained attention / vigilance task. This was the top follow-up candidate from Campaign 009 (evaluated but not built).

Requirements:
- Materially distinct from `attention-visual-search`, `attention-odd-one-out`, `attention-target-count`, `attention-symbol-tracker` — document the rationale.
- Deterministic stimulus stream (seeded, replayable).
- Go/no-go or rare-target mechanic with configurable target rarity per difficulty.
- Reaction timing via the injectable monotonic clock (`sdk/timing.ts`).
- Named difficulty mappings; adaptive-profile seam; pause/resume freeze semantics; AppState auto-pause.
- Scoring + result model consistent with existing result contracts (`sdk/types/results.ts`).
- Tutorial; dev-gated QA hooks (force-win path); semantic testIDs; sensory vocabulary via shared SFX aliases; accessibility semantics (challenge hidden while paused, roles/labels); registry-ready `game.json` metadata.

Build the complete production vertical slice per README §7 (all module files). Do NOT write the giant validation suite now — ≤8 small determinism tests allowed.
