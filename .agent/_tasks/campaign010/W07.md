# W07 — Advanced Personalization V2

## Mission

Build a stronger, explainable recommendation layer on existing local history.

Create `apps/mobile/src/personalization/**` (NEW module) implementing transparent weighted-component scoring with signals such as:
- weak domain, undertrained domain, staleness
- recent overexposure / game fatigue / novelty
- difficulty fit, performance trend
- personal best proximity
- workout composition fit

Requirements:
- Every signal is explainable: produce human-readable reason strings/keys consumable by UI.
- Deterministic where feasible (injectable clock; no wall-clock surprises).
- All signals derived from stored local data (sessions, ratings, history) — no cloud, no AI API.
- Refactor `src/workout/personalize.ts` to consume the new module while KEEPING its public export names/signatures backward-compatible — `workout/today.ts` consumes it and is owned by W06. If a signature change is unavoidable, do NOT make it: NEEDS_PARENT.
- Do not invent monetization restrictions or entitlement gating.
