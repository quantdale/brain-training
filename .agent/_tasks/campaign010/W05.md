# W05 — GameHost / Game Platform Consolidation (debt D1)

## Mission

Implement the Campaign 009 architecture-debt item D1: reduce repeated lifecycle/screen plumbing across game implementations by creating shared GameHost infrastructure, then migrate representative simple games onto it.

Evidence (from `docs/audits/campaign009-architecture-debt.md` D1): every game screen duplicates `newSessionId()`/`randomSeed()` (36 copies), AppState auto-pause effects, tutorial open/complete/skip wiring, QA-panel gating (`isDevBuild()`), intro/difficulty/start layout, pause/resume plumbing. A single game screen is ~600 lines, majority boilerplate.

Create `apps/mobile/src/components/game-host/**`:
- `useGameSession` hook owning: collision-safe session id + seed creation, AppState auto-pause with frozen-clock resume, pause/resume state, background state.
- `<GameHost>` component owning: intro/difficulty/start layout, tutorial gating lifecycle, QA controls panel (dev-gated), pause overlay mount, results transition handoff, error state, timer lifecycle helpers, game header.
- Design so each migrated game reduces to roughly generator + reducer + view.

CRITICAL constraints:
- Read `src/sdk/__tests__/catalog-contracts.test.ts` FIRST. The source-scanning contract suite asserts lifecycle/pause/QA/testID/tutorial patterns over every game module. Either design GameHost so migrated modules still satisfy the scanner, or make the MINIMAL contract-test update recognizing GameHost-based modules (document it — this is part of the architecture change, not test expansion).
- Do NOT edit `components/game-ui/**`, `components/a11y.ts`, `components/screen-shell.tsx` (owned by W14/W16) — consume them.
- Migrate representative SIMPLE games only. Suggested set (verify simplicity yourself): `speed-reaction-time`, `math-fast-math`, `attention-visual-search`, `language-word-scramble`, `spatial-coordinate-turn`, `flexibility-card-sort`. Check `src/app/__tests__/__snapshots__/visual-baselines.test.tsx.snap` first: prefer migrating games WITHOUT visual baselines; if you migrate one that has baselines, record "visual baseline regeneration debt" in your NOT VALIDATED gaps instead of editing snapshots.
- New games being built concurrently (W01–W04) use current patterns — do not touch them and do not block on them.
- Also implement the Android hardware-back seam (xplat audit B6): intercept back during an active session with a pause/confirm dialog inside GameHost for migrated games.
