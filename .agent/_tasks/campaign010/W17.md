## Implementation summary
Migrated all six assigned games onto the Campaign 010 GameHost (`@/components/game-host`), following the `math-fast-math` exemplar:

- `attention-target-count/screen.tsx`, `attention-symbol-tracker/screen.tsx`, `memory-grid-recall/screen.tsx`, `math-missing-operator/screen.tsx`, `logic-next-sequence/screen.tsx`, `spatial-fold-match/screen.tsx`.
- In every screen: replaced the duplicated session id/seed helpers (`randomSeed`/`newSessionId`), direct `SessionLifecycle` ownership, `finalizedRef`, AppState auto-pause effect, intro/difficulty/start layout, in-session header (round label / score / pause), QA-panel gating, pause-overlay mount, and results chrome with `<GameHost>` + `useGameSession` + `<GameResults>` (+ `useGameInterval` where the game had a pacing interval). Seed now flows through `resolveSessionSeed(sessionSeed)`; finalization uses `claimFinalize()`/`completeIfActive()`/`elapsedMs()`/`pausedDurationMs()`; hardware-back guard via `interceptBack={inSession}`.
- Game-specific logic untouched: reducers, generators, scoring, session persistence, difficulty, hooks, tutorial/QA components, per-round freeze-and-continue timers (target-count countdown, symbol-tracker observe, grid-recall study, fold-match reveal+choice), missing-operator's clock-anchored round-budget timeout and `pausedAtMs`/`resumedAtMs`/`roundStartedAtMs` reducer fields, next-sequence's lifecycle-elapsed response-time baseline (kept keyed on phase only so the baseline is not reset mid-round).
- Deleted the six per-game `components/pause-overlay.tsx` re-export files (host mounts the shared overlay); all semantic testIDs preserved (`screen`, `intro`, `start`, `help`, `difficulty.*`, `round.N`, `score`, `pause`, `pause-overlay`, `resume`, phase views, stat rows, `results`, `qa-toggle`, etc.). Screens keep an `isDevBuild()` reference (tutorial skip) as the contract scanner requires.
- Validation: ONE `npx tsc --noEmit` from apps/mobile — clean, zero errors. One targeted run of `npx jest src/sdk/__tests__/catalog-contracts.test.ts` — 16/16 passed (whole-catalog scan includes these six games as GameHost-delegating modules). No NEEDS_PARENT items.
