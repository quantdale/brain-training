# Swarm Task Packets

Create task packets here when a campaign is partitioned for parallel coders.

Suggested filename: `001-a-short-name.md`.

Every packet must specify:

```markdown
# Task Packet

Campaign:
Status: READY | ACTIVE | DONE | BLOCKED
Owner role:

## Objective
## Dependencies
## Allowed write surfaces
## Forbidden/shared write surfaces
## Completion criteria
## Cheap validation
## Integration notes for orchestrator
## Result/evidence
```

Task packets are execution artifacts. Archive/summarize completed packets rather than keeping stale active work indefinitely.
