076-f: owner-directed controller switch to DeepSeek V4.1 Flash, and a helper that never stores the key

The owner directed two changes to the external ARTEMIS controller, both
consequences of the measured timeouts: the sweep's controller tasks kept hitting
the provider's per-call deadline with the previous model, and the controller was
returning timed-out sessions with unfilled notes.

1. Credential. A new OpenDesign key was supplied. It is written ONLY to the
   external D:\Tools\artemis\.env - that file is outside this repository and
   outside Git. scripts/qa/set-artemis-key.mjs performs the replacement by
   reading the key from an environment variable, so the key is never a literal in
   any tracked file, never appears in a commit, and never appears in a log. The
   helper reports only that the key was replaced and its length, never its value.

2. Model. artemis.jsonc's default, planner, operator and hopper nodes moved from
   mimo-v2.6-flash to deepseek-v4.1-flash on the same provider, with
   thinking_level and reasoning_effort at HIGH per owner directive. The hopper
   stays on low effort because it is a package-name locator where reasoning buys
   nothing and costs latency; include_thoughts stays off on operator because the
   gateway returns reasoning content ARTEMIS's ChatMessage schema rejects, and
   dropping the thought echo does not reduce the reasoning itself.

   The previous 'low' pins are not silently discarded: they are recorded in the
   config comments as measured costs of the EARLIER model - a high-effort plan on
   that model blew ARTEMIS's per-call deadline. That was a property of that model,
   not of the requirement, so the owner's directive takes precedence and the
   measured cause is kept.

Verified before resuming: the daemon restarts clean, `artemis doctor` reports
Ready with deepseek-v4.1-flash as the planner model, and one real authenticated
task completed (session 1873f3bd, 216 s) with the model confirmed on Planner,
Hopper and Outputter. No credential or raw trace is stored in this repository.
