## Why

Several Games covers are pixel-identical despite representing different activities. Players must read titles because the current renderer collapses game mechanics into shared grids and blank chips.

## What Changes

- Audit all 42 implemented mechanics and assign one intentional, recognizable cover to each stable game ID.
- Extend Play Lab's matte learning-tool language with precise mechanic illustrations and selected original ImageGen artwork.
- Carry each identity through library, detail, introduction and small companion art without altering gameplay.
- Validate title-hidden recognition, domain similarity, Android presentation, offline loading and measured performance.

## Capabilities

### New Capabilities

- `game-cover-identities`: Complete, mechanic-specific offline cover identities with stable mapping and accessible presentation.

### Modified Capabilities

None. Existing discovery, routing, gameplay and persistence behavior is preserved.

## Impact

Discovery artwork components, local illustration assets, deterministic authoring tools, focused tests and evidence. No game rules, registry IDs, persistence, dependencies at runtime, navigation or global UI redesign.
