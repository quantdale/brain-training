# Campaign 050 — Integrated Release Candidate Certification

## Objective

Determine what is actually certifiable after Campaigns 043–049 by rechecking
the current repository, release artifact, protected data contracts, catalog,
responsive matrix, performance evidence, and known external boundaries.

## Required current-state validation

- full Jest and authoritative repository validators;
- typecheck, lint, Expo Doctor, dependency policy, and raw audit classification;
- web export and offline/workflow checks;
- Android debug/release build and release launch without Metro;
- full four-game workout and representative standalone games;
- all-42 registry/lifecycle summary from the current product lineage;
- result persistence, force-stop/relaunch, backup/import smoke, and offline;
- Home, Games, Progress, Profile, Rewards, and Data Management;
- invalid-route recovery, current accessibility/state matrix, and performance;
- current external CI state, copy/medical-claim review, and Git provenance.

## Non-goals

No feature expansion, redesign, dependency churn, store publication, signing
credential use, clinical efficacy claim, human usability substitution, or
reopening of locked product decisions.
