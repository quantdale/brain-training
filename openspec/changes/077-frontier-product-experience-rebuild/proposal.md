## Why

The owner rejected the actual Campaign 076 app after using it: inconsistent iconography, weak artwork and composition, layout glitches, confusing games, and gameplay mistakes remain despite earlier automated acceptance. Campaign 077 must deliver a substantially better working product through fresh evidence, independent critique, original artwork, and correctness repairs.

## What Changes

- Audit every application surface and all 42 registered games; classify KEEP, REFINE, REDESIGN, or REBUILD using concrete findings.
- Research real Refero styles, mobile screens, and flows; compare at least three distinct directions and select one coherent reference lock.
- Generate, inspect, optimize, and bundle original ChatGPT ImageGen artwork; standardize functional vector icons separately.
- Reconstruct the shared visual system, typography, navigation, controls, game chrome, feedback, motion, and accessible responsive layouts.
- Redesign Home, discovery, game introductions, results, Progress, Rewards, Profile, settings, data ownership, and supporting states where the audit establishes weaknesses.
- Repair demonstrated game mechanics, scoring, input, timer, lifecycle, and content defects with fail-before/pass-after regression coverage and correct version metadata.
- Capture a new Campaign 077 baseline and matched post-change emulator screenshots, with build identity, requested versus observed theme, and responsive/sensory profiles.
- Certify data integrity, offline operation, native builds, clean checkout, relevant tests, permissions, and four GitHub Actions at the actual ending SHA; leave Home running in the visible dedicated emulator.

## Capabilities

### New Capabilities

- `frontier-product-experience`: researched visual/art system and complete product surface recovery, preserving proven product contracts.
- `gameplay-correctness-recovery`: current game-by-game assessment, reproducible defect closure, honest feedback, fair input and timing.
- `frontier-experience-certification`: fresh provenance, visual profiles, independent critique, runtime/data/engineering certification, and visible owner handoff.

### Modified Capabilities

None. These campaign requirements supplement existing game, persistence, and product specs; locked product systems and historical session interpretations remain protected.

## Impact

React Native/Expo app routes, shared UI/theme/motion, game presentation and defect-specific module logic/content, bundled assets, deterministic regression tests, evidence tooling, and campaign records. SQLite formats, game identities, append-only economy, optional cloud boundary, and offline operation remain protected; any necessary persistent-format change requires an explicit safe migration and regression proof. No framework-wide upgrade, native rewrite, account/social/paywall expansion, store publication, physical-device or iOS-runtime readiness claim is authorized. Campaign 076 evidence and open task 14.3 remain historical and unmodified.
