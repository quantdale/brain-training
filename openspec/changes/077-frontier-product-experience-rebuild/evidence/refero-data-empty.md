# Data and recovery reference supplement

Actual tools: `refero_get_screen` batch and `refero_get_screen_image` full images,
2026-10-14. These complete the settings/data/empty-state research gap; they are
reference evidence, not screens copied into Brain Training.

- FocusPomo, [data-operation history](https://refero.design/screens/2b92e90f-8044-43ad-85a0-0c5b64e8ee60): operation name, explicit timestamp and success outcome are adjacent. Adopt that immediate confirmation for local backup/import and preserve a clear operation context. Reject the tall repeated rounded cards and warm palette, which conflict with the selected compact cool system. Do not add a new sync log or cloud feature.
- IFTTT, [empty activity](https://refero.design/screens/42bf3e8e-5ac4-46cb-a38a-502cfdc46c9f): a plain empty-state explanation and one retry action communicate absence of activity. Keep absence distinct from loading and failed storage reads. Reject oversized black header/refresh symbols and excessive blank space; use the app's bounded state panel and one vector family.

Both actual full images were inspected. Source state and app contracts determine
the behavior; the references only inform hierarchy, copy and action placement.
