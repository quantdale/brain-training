## Rules applied

- An intro screen, an unanswered board, or a filename is **never** counted as
  scored feedback. Scored feedback requires a quoted correct/incorrect/timeout
  verdict observed on the device.
- A controller note that is an unfilled skeleton is **not** a reviewed row.
- A note that describes a *different* game is **not** acceptance of this game.
- A historical frame never becomes a current-device row. The 22 games whose
  parent tasks are already checked get a fresh row here regardless — those
  existing checks are **not** treated as this review (task 3.21).

## What a NOT VALIDATED row means

It means the check did not establish the required states. It is **not** a
claim that the game is broken, and **not** a pass. Per the change spec a
parent task is checked only when its own linked evidence satisfies it, so a
`NOT VALIDATED` row leaves the corresponding parent task unchecked.
