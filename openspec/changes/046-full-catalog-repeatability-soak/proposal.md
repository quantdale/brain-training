# Campaign 046 — Full Catalog Repeatability & Game-Lifecycle Soak

## Problem

The catalog has 42 registered games. Existing evidence proves broad structural
contracts and selected real lifecycles, but the next campaign must re-prove the
current catalog as a system after the Campaign 045 dependency checkpoint.

## Outcome

Collect current evidence for every registered game across detail, start, first
interactive state, legitimate result completion, persistence, and navigation
return. Repeat complete lifecycles with real mechanic interaction for a
risk-weighted subset spanning all eight domains/mechanic families. Inspect the
dedicated device database for duplicate sessions, ratings, currency operations,
or stale metadata.

## Non-goals

No product feature wave, major architecture rewrite, catalog expansion, CI
masking, or claim that deterministic QA completion substitutes for mechanic
correctness.
