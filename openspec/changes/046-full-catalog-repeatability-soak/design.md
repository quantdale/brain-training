# Design — Campaign 046

Use the generated registry as the authoritative 42-game roster. Use current
release/debug artifacts and only the dedicated `emulator-5554`; prefer ARTEMIS
for natural-language runtime journeys and emulator-local accessibility/ADB
inspection for deterministic checkpoints. Record each game's lifecycle stage
separately: route reachability, first interaction, legitimate result,
persistence, and return navigation. Record deterministic force-completion and
real mechanic interaction as different evidence classes.

No game module or shared SDK contract should be edited unless a current
reproducible defect is isolated and the repair is necessary for progression.
