# Campaign 051 — Visual DNA Reboot & Massive UI Overhaul

## Objective

Make the product feel like a memorable pocket cognitive arcade: a training
console with tactile controls, collectible game worlds, strong hierarchy, and
credible progress language. The current product is functionally mature but
its visual grammar still reads as a stack of similar rounded cards and neutral
dashboard surfaces.

## In scope

- Fresh research-led visual direction selection with Refero and imagegen.
- A new token and shape system with light/dark parity, large-text safety,
  reduced-motion behavior, and accessible contrast.
- A catalog-wide eight-domain visual world system plus mechanic signatures for
  all 42 registered games.
- Home, Games, Game Detail, GameHost/gameplay, Results, Progress, Profile,
  Rewards, Data Management, and navigation chrome transformations.
- Evidence-backed visual critique, responsive/a11y review, native rebuild and
  repository validation.

## Non-goals

- No changes to scoring, generators, session persistence, SQLite schemas,
  reward ownership, workout advancement, routing contracts, or the Game SDK.
- No clinical efficacy or medical claim.
- No store publication, credentials, human usability substitution, or
  external CI claim.
- No dependency churn unless an actual implementation blocker is proven.
