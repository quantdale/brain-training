# Design — Campaign 051

## Locked direction

Choose **Signal Arcade**: an original analog-arcade graphic system using ink
navy, warm paper, signal coral, electric cyan, voltage yellow, and mint. The
system borrows Playdate/EVOKE's flat graphic confidence, Apple Games' object
first empty states, Duolingo's completion delight, Brilliant's interaction
focus, and bounded Active Theory/Peloton dark performance framing. It does not
copy any reference, use a default indigo dashboard, or average the three
directions.

## Implementation seams

1. Tokens remain the single source of truth. Add the Signal Arcade palette,
   display hierarchy, cut/block shape vocabulary, restrained elevation, and
   motion/sensory rules without removing existing semantic token names.
2. `GameWorldArt` is code-native and presentation-only. It combines the eight
   domain worlds with the stable mechanic family/motif metadata, so every
   catalog entry gets a recognizable stage without touching registry or game
   logic.
3. Home gets one dominant daily-console object and a single Start/Continue
   decision. Games becomes a poster-like storefront with discovery controls.
   Detail leads with fantasy and Play. GameHost makes the mechanic stage own
   the screen. Results turns completion into a bounded emotional peak.
4. Progress stays analytical: strong framing, domain rails and calm charts,
   not arcade noise. Profile, Rewards, and Data Management use collectible,
   trustworthy groupings with explicit ownership language.
5. Stable test IDs and accessible names remain on the semantic controls. New
   art is decorative and never the only explanation. All movement collapses
   under reduced motion and all sensory feedback remains gated by settings.

## Convergence

The orchestrator will run source/type/test/lint/export/build checks after the
implementation wave, then the two required visual critiques: remove any
remaining generic card soup, then remove any over-saturation/noise/accessibility
or performance regression. The final packet records what was actually
validated and what remains external or unavailable.
