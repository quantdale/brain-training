# Campaign 035 — Cross-Surface Visual System Consolidation

## Problem

The shared shell and library use neutral elevated surfaces with domain color
as a taxonomy cue, but the single-game Game Detail and GameHost intro heroes
use a full domain wash and thick domain border while their primary Play/Start
CTA uses the global accent. The live pixels make the domain decoration compete
with the action hierarchy.

## Outcome

Use the shared neutral hero surface for the single-game identity contexts.
Retain domain color in the identity motif and category cue so the catalog
vocabulary remains recognizable, while the primary CTA becomes the clear
state action. Preserve all game mechanics, session contracts, IDs, and copy.

## Non-goals

No gameplay, scoring, persistence, schema, economy, navigation, game identity
metadata, dependency, accessibility-contract, or broad token-palette rewrite.
