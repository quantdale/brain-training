# Design — Campaign 042

## Defect isolation

Use the smallest evidence-backed seam for each reproduced issue. For SQLite,
preserve the existing schema and local persistence contract while preventing
shared native handles from racing or surviving runtime teardown in a poisoned
cache. For large text, preserve Results content and hierarchy while tightening
only the local hero density at the demonstrated font-scale threshold.

## Validation matrix

| Concern | Required proof |
| --- | --- |
| SQLite startup | Pre-repair reproduction, source/root-cause isolation, focused tests, final cold/transition/relaunch logs |
| Game lifecycle | Real mechanic evidence, deterministic completion label, result UI, direct SQLite retention, duplicate-operation query |
| Release/a11y | Non-debuggable installed APK, no Metro, 22 route/theme surfaces, XML/pixel audit |
| Responsive | Compact and font-scale-2 matrices, final actionable bounds, pre/post comparison |
| Persistence | Favorite, theme, pause/resume, offline relaunch, integrity/schema checks, migration/portability test evidence |
| Governance | Local test/build/validator gates, external CI run classification, durable-state convergence, adversarial second pass |

Unavailable human/platform/system-sheet checks are recorded as NOT VALIDATED;
they are not inferred from emulator automation.
